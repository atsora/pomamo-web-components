Attributes
operation-id
Id of the operation: the documents of its active revision. A change sends a new request.
component-id
Id of the component, or of the part (same id). A change sends a new request. With neither id, the button stays hidden without any request.
operation-display
Display name of the operation, for the documents dialog.
component-display
Display name of the part or of the component, for the documents dialog.
component-kind
Part (default) or Component, for the documents dialog.
path
This parameter can be used for tests. It is read in configuration filled by x-checkpath.
