Renders a colored bar of CNC alarm severity slots over the asked range (green=ok, yellow=warning, blue=info, red=error). The mock divides the asked range proportionally, so the bar always fits regardless of the time of day at which the demo is opened.

Machine 1 — 5 segments: green / yellow / green / red / green (machine-id=1)

Machine 2 — 4 quarters: green / blue (info) / green / yellow (warning) (machine-id=2)

Machine 3 — clean run then red alert in the last 1/8 of the range (machine-id=3)

Error — server HTTP 400 (nothing displayed) (machine-id=999)

Empty payload — graceful fallback (machine-id=997)
