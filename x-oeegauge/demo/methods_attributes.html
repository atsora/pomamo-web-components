Attributes
machine-id
Id of the machine or of the group to display.
oee-type
oee (default, TRS), ooe (TRG) or teep (TRE).
period-context
Context of the dateTimeRangeChangeEvent giving the range. Without a range, the current shift is displayed.
current-shift
Always display the current shift (the current day when there is no shift), whatever the period.
machine-context
Context of the machineIdChangeSignal event.
thresholdtargetoee, thresholdredoee, thresholdtargetooe, thresholdredooe, thresholdtargetteep, thresholdredteep
Color thresholds in % (defaults: OEE 85 / 60, OOE 75 / 50, TEEP 60 / 40).
path
REST base path. Read from configuration when not provided.
