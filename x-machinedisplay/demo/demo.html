Displays a machine's name from Machine/Name?MachineId=<id> (or ?GroupId=<id>). The component auto-shrinks long names to the container width.

Machine 1 — "Machine 1" (machine-id=1)

Machine 3 — "Machine 3" (machine-id=3)

Group 101 — "Milling cell" (group=101)

Narrow container (100 px) — name shrinks to fit

Very narrow container (30 px) — extreme shrink

Error — server HTTP 400 (machine-id=999)
