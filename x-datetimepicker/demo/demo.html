Input for a single date/time. Combines 3 axes: showseconds, nullable, and mindatetime/maxdatetime bounds. The button below reads each picker's current ISO value.

Default — minutes only, current datetime, no bounds

Full options — seconds, nullable, bounded (08:00 – 15:00 UTC), default at 05:06:07

Nullable, null — empty state with custom no-value text

Edge case — default above max bound (15:06:07 > maxdatetime 15:00:00)
