Attributes
textchange-context
Base context of the textChangeEvent. When it contains machine-id or group, _<value> of that attribute is appended.
machine-id
Machine id, used to build the context.
group
Group id, used to build the context.
Methods
cleanDisplay ()
Empty the displayed text.
Events
textChangeEvent (listened)
{ text }: text to display (HTML). An empty text clears the display.
askForTextChangeEvent (dispatched)
Sent to the context at initialization to get the current text.
