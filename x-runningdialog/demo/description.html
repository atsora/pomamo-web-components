Body of the running dialog, opened by x-showrunningdialogbutton. It displays a period toolbar and a clock, then one tile per machine of the group (x-grouplist): machine name, reason button, current information, bars (x-barstack), motion percentage and motion time. The current information depends on the configuration: currentdisplay.displayjobshiftpartcount (default false), currentdisplay.displayjob, currentdisplay.displayshift and currentdisplay.displaycncvalue (default true).
