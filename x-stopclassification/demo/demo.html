Dialog/form for classifying a machine stop. The component switches between flat layout (one tile per reason) and grouped layout (collapsed by category) when the count of visual units exceeds the threshold (stopclassification.maxflat, default 11). Each scenario below probes the threshold boundary.

Machine 1 — 8 reasons, well under limit → flat layout (machine-id=1)

Machine 2 — 11 reasons, exactly at limit → still flat (machine-id=2)

Machine 3 — 12 reasons, one over → all reasons grouped by category (machine-id=3)

Machine 4 — Quality category marked AlwaysSecondLevel → flat + 1 clickable group (machine-id=4)

Error — server HTTP 400 (machine-id=999)
