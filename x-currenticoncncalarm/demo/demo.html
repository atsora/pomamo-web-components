The icon variant follows the alarm Focus field: focused (operator must act), ignored (acknowledged), or unknown (focus annotation missing).

Mill-01 — focused alarm

Spindle overheat, Focus=true → red focused icon

Mill-02 — ignored alarm

Door open, Focus=false → grey ignored icon

Lathe-01 — unknown alarm

Probe contact, no Focus annotation → "unknown" variant

Manual-01 — no alarm

CncAlarms array empty → icon hidden

Error case (reserved id 999)

HTTP 400 from mock → icon hidden, no console error
