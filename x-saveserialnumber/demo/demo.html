Form to enter a serial number on a cycle. The 3 scenarios below vary the starting state of the input (pre-filled / empty / multi-part).

Machine 1 — pre-filled serial (ABCD-001), begin marker (machine-id=1)

Machine 2 — empty serial (operator to enter), end marker (machine-id=2)

Machine 3 — long pre-filled serial (XYZ-2026-005-A-revB) (machine-id=3)

Error — server HTTP 400 on save (machine-id=999)
