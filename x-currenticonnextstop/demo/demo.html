The icon stays hidden when nothing requires attention. It only becomes visible for an active stop (severity Error) or an imminent coming stop (severity Warning, < 180 s).

Machine 1 — active stop (Error)

Stopped 4 min ago → red icon visible

Machine 2 — imminent coming stop (< threshold2)

Stop in 90 s, Warning severity → orange icon visible

Machine 3 — coming stop above thresholds

Stop in 7 min → component keeps icon hidden (no urgency)

Machine 4 — no event

No active or coming stop → icon hidden

Error case (reserved id 999)

HTTP 400 from mock → no icon, no console error
