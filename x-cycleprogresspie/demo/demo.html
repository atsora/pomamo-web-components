Renders a circular cycle progress pie colored by the next-stop severity. The mock varies the cycle state per machine; the demo also illustrates the 3 supported sizes (small / default / big).

Machine 1 — 33 % in SEQ2 (Drilling), active error, default size (machine-id=1)

Machine 2 — 58 % in SEQ3 (Finishing), warning in 90 s, big size (machine-id=2)

Machine 3 — 92 % in SEQ4 (Inspection), small size (machine-id=3)

Machine 4 — idle (no operation), default size (machine-id=4)

Error — server HTTP 400, big size (machine-id=999)
