Attributes
group-id
Group id passed to the /Signal/ endpoint as ?GroupId=<value>. Use a single id, a composite key (e.g. "1_23_53"), or the special value "ALL".
refresh-rate
Polling interval in seconds. Defaults to 30s.
path
Base URL of the REST API. Read from configuration (typically filled by x-checkpath) or from the attribute for tests.
Endpoint & response shape
GET /Signal/?GroupId=<group-id>

{
  "Messages": [
    {
      "Message": "Maintenance scheduled at 14:00",
      "BgColor": "#FFC107",
      "FgColor": "#000000"        // optional, auto-contrast if empty
    }
  ]
}
The Message text is used as the dismiss key (per-session).
