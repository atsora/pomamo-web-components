Attributes
templateid
Id of the element to clone for each machine (default boxtoclone).
group
Group id(s), comma-separated, to read the machines from (auto read from config).
machine
Fixed list of machine ids (ex: 1,2,3), used when group is empty (auto read from config).
forcestaticlist
True to load a dynamic group only once (no refresh).
no-rotation
When present, ignore the updateVisibleMachines event.
refreshrate
Refresh interval of a dynamic group, in seconds (default 30).
path
REST base path. Read from configuration when not provided.
Methods
getMachinesList ()
Current machine ids, comma-separated.
