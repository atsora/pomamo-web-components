Attributes
machine-id
Id of the machine to display in this widget.
machine-context
Event bus context for receiving `machineIdChangeSignal` messages.
path
Base URL of the web service (typically set via x-checkpath configuration).
status-context
Event bus context to dispatch `workinformationStatusChange` (used to display icons under the machine name in machineTab).
period-context
Event bus context for `dateTimeRangeChangeEvent`.
