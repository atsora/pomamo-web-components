Form that assigns a machine-state template (Production / Setup / Maintenance / Off) to a time slot. The mock returns the same list of templates regardless of machine — vary `machine-id`, `mst-id` (current template, filtered out of the dropdown) and `range` to see different starting points.

Machine 1 — no current MST, 2 h slot at 06:06 (machine-id=1)

Machine 2 — current MST = Production (7), morning shift slot (machine-id=2)

Machine 3 — current MST = Maintenance (9), afternoon slot (machine-id=3)

Error — server HTTP 400 on the MST list (machine-id=999)
