Vertical stack of bars for one machine, driven by the configuration of its period-context: thin bars on top (showcoloredbar.shift, machinestate, observationstate, cycle, operation, isofile), then the main bar with its overlays (showcoloredbar.cncalarm, redstacklight, timeselection), then the bars below (showcoloredbar.cncvalue, highlightperiods). The main bar is set by main-bar; without it, the running bar is used when showcoloredbar.running is true, otherwise the reason and production state bars are both created and showproductionbar selects the visible one. The stack takes the height of its container.
