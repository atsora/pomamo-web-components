Shows the current machine state template (Production / Setup / Maintenance / Off) with an inline editor.

Machine 1 — current MST (machine-id=1)

Machine 2 — current MST (machine-id=2)

Machine 3 — current MST (machine-id=3)

Machine 4 — set-up (machine-id=4)

The current state template is in the set-up category (Category: 2): the label gives way to an x-setupmachine, which shows the running operation and how long the set-up has lasted. Past thresholdinseconds, 60 s by default, the elapsed time turns to the bad efficiency color.

Machine 5 — stopped (machine-id=5)

State template "Off", id 3. Open this page with ?stoppedIds=3 to watch the classification dialog open on its own here, and close again as soon as the machine leaves that state template. Several ids are allowed, as in ?stoppedIds=3,4.
