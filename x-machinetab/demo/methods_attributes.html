Attributes
machine-context
Event-bus context used to dispatch machineIdChangeSignal when a tab is clicked, and to listen to askForMachineIdSignal.
period-context
Forwarded to icon children (x-currenticonunansweredreason, x-currenticonworkinformation, x-currenticonnextstop, x-currenticoncncalarm) for dateTimeRangeChangeEvent.
status-context
Forwarded to icon children for reasonStatusChange / workinformationStatusChange.
path
Base URL for AJAX. Read from configuration filled by x-checkpath; can be overridden via attribute for tests.
Events
machineListChanged (in, global)
Drives the tab list. Payload: { ids: string[], source?, error? }. The component does not fetch the machine list itself — it relies on x-machineselection (or any other dispatcher) emitting this signal.
machineIdChangeSignal (out, on machine-context)
Fired with { newMachineId } when a tab is clicked or the mobile chevrons are used.
Config keys read
componentsToDisplay (array)
Drives icon visibility: x-lastmachinestatus → unanswered-reason icon, x-lastworkinformation → missing-work-info, x-cycleprogressbar → next-stop, coloredbar + showcoloredbar.cncalarm → CNC-alarm icon.
refreshingRate.currentRefreshSeconds (int)
Polling interval for CurrentReason per tab (default 10 s).
