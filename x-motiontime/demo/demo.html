Accumulates the running-motion duration from a sibling x-reasonslotbar via motionChangeEvent on the shared motion-context. Each machine below has a different motion ratio.

Machine 1 — 50 % motion (4 h / 8 h) (machine-id=1)

Machine 2 — 75 % motion (6 h / 8 h) (machine-id=2)

Machine 3 — 62.5 % motion (5 h / 8 h) (machine-id=3)

Error — sibling bar fails to load (motion-context never fires) (machine-id=999)
