Attributes
machine-id
Id of the machine to display in this widget. This parameter can be used to complete motion-context when using x-grouparray.
machine-group
Machine group of the task service, when no machine-id is set: a group id, or machine ids separated by ','.
all-machines
Tasks of the machines selected in the page (x-machineselection), when neither machine-id nor machine-group is set.
show-role
Displays the role of each task. Not displayed by default: the page lists the tasks of one role.
mockGraphqlUrl
For the development only: GraphQL endpoint to use instead of <path>optasks, for example http://localhost:4000/optasks (atsora-mocks).
